# AZMY EHAB — Official Website

A fast, responsive personal links website for AZMY EHAB.

## Highlights
- Clean HTML5 + CSS3 + Vanilla JavaScript
- No framework, no build step
- Mobile-first responsive UI
- Premium glassmorphism with lightweight 3D motion
- Custom branded favicon (PNG + SVG)
- Updated X and Snapchat links
- Local InstaPay and Vodafone Cash brand icons
- SEO metadata, Open Graph, JSON-LD, robots.txt and sitemap.xml
- Automatic copyright year
- Accessible labels and reduced-motion support
- No share/copy controls

## Favicon / Google Search
The site provides a stable square favicon and `rel="icon"` tags. Google notes that a favicon can appear in Search when the page and icon are crawlable, but Google does not guarantee that it will display immediately; recrawling can take days or weeks.
